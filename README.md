# นทีราตรี — คืนวันเพ็ญริมสายน้ำ

เว็บจำลองงานลอยกระทงแบบสามมิติด้วย Three.js ตอบสนองต่อหน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์

## เปิดใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ที่รองรับ WebGL ได้โดยตรง ไม่ต้องติดตั้งแพ็กเกจหรือเปิดเซิร์ฟเวอร์ แต่ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Three.js จาก CDN และแบบอักษร Kanit / Noto Serif Thai หากไม่มีอินเทอร์เน็ต ฉากสามมิติจะไม่เริ่มทำงาน

## การใช้งาน

- เลือกช่วงเวลา **เช้า / เย็น / กลางคืน** เพื่อเปลี่ยนแสงและกิจกรรมในฉาก
- ตอนเช้า พระเดินบิณฑบาตและผู้คนใส่บาตร กด **ใส่บาตร** หรือแตะร้านค้าเพื่อดูรายการสินค้า
- กด **ลอยกระทง** ใส่ชื่อ เพิ่มรูปได้ตามต้องการ และเลือกกระทง 9 แบบ กระทงจะลอยบนแม่น้ำสามมิติ
- เขียนคำอธิษฐานก่อนส่งกระทง ระบบจะแสดงคำอธิษฐานบนกระทงและพากล้องติดตามกระทงที่เพิ่งลอย
- กระทงมีแสงเทียนและธูปควันลอยไหว ปล่อยจากปลายท่าน้ำลงแม่น้ำที่ขยายกว้างขึ้น แล้วลอยไปทางขวาโดยกระจายตัวไปตามแนวกระแสน้ำ
- กด **ปล่อยโคม** เพื่อสร้างโคมลอยแบบกำหนดเองจาก 9 แบบ แล้วดูโคมลอยขึ้นเหนือเมืองตามแรงลมที่พัดได้หลายทิศทาง
- โคมทั้ง 9 แบบเป็นโคมกระดาษสา/โคมล้านนาลายไทย พร้อมเขียนคำอธิษฐานบนโคมได้
- ตอนกลางคืนจะมีพลุสีสุ่มขนาดเล็กเป็นครั้งคราว หรือเลือกสีแล้วแตะตำแหน่งในฉากเพื่อจุดเอง
- ลากบนฉากเพื่อหมุนมุมมอง ใช้ล้อเมาส์หรือ pinch เพื่อซูม และกด **มองท่าน้ำ** เพื่อไปยังจุดลอยกระทง/ปล่อยโคม
- กด **เปิดเสียง** เพื่อเล่นเสียงสังเคราะห์จากเบราว์เซอร์

ท่าน้ำทำเป็นสะพานไม้ยื่นเหนือน้ำ มีผู้ร่วมงานมาเป็นคู่และเดี่ยว โดยคู่จะขยับเข้าหากันและทำกิจกรรมเป็นจังหวะ คนลอยกระทงจะก้มตัวประคองกระทง วางลงน้ำ แล้วค่อยยืนขึ้น ส่วนคนปล่อยโคมจะยกโคมเหนือศีรษะและปล่อยให้ลอยขึ้น อีกฝั่งเป็นผืนน้ำเปิด ไม่มีแนวหมู่บ้านบังทิวทัศน์ โคมลอยทั้งหมดเป็นแบบตกแต่งลายไทย/ล้านนาและลอยแยกทิศทางตามแรงลม

ฉากอาคาร ตลาด วัด ต้นไม้ แม่น้ำ โคม กระทง และตัวละครสร้างจากเรขาคณิต Three.js แบบ procedural พร้อมท้องฟ้าไล่สีและเมฆบาง ๆ โดยจำกัดอัตราเรนเดอร์และปิดเงาแบบเรียลไทม์เพื่อช่วยลดอาการหน่วง จึงเป็นโมเดล 3D จริงแต่มีรูปแบบเชิงภาพประกอบ ไม่ใช่โมเดลสแกนหรือภาพถ่ายสมจริง การลอยกระทง การใส่บาตร และการปล่อยโคมเป็นการจำลองในหน้าเว็บเท่านั้น ห้ามนำไปใช้แทนคำแนะนำการจุดหรือปล่อยโคมจริง
